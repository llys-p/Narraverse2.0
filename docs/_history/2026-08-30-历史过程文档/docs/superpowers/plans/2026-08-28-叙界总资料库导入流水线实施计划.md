# 叙界总资料库导入流水线实施计划

**目标：** 在保留现有素材加载能力的前提下，把普通导入改成 Master-first：原件和规范对象先入总库，安全自然语言字段经现有 HY-MT 队列翻译并持久化为版本，必需字段就绪后再生成当前冒险的独立 Lore 实例；高级模式可明确选择临时直导。

**现行规格：** `docs/superpowers/specs/2026-08-28-叙界总资料库与导入翻译流水线设计.md`

**实现原则：** 复用现有 Go 解析/投影、8097 队列和 React 导入弹窗；不新增运行时依赖，不实现三方合并、语义搜索、旧冒险批量迁移或总库管理大界面。
