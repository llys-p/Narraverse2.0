## 1. 整合目标与背景

### 1.1 现状（实地核验）

**文字冒险平台**（纯静态 SPA，无构建）：
- app.js 约 5000 行、**305 个顶层函数**、40 个功能分组、18 个弹窗、4 个侧栏抽屉、5 个脚本。
- 功能面（按分组）：全局状态 / 26 类冒险类型 / IndexedDB 持久化 / 冒险管理与两步向导 / System Prompt 构建与 World Info 注入 / API 调用与流式解析 / 上下文压缩与摘要编辑 / 角色卡与设定书管理（含 PNG 卡解析、chub 导入）/ Agent 状态面板 / 提示词编辑器 / 命令面板(Ctrl+K) / 场景配图 / 曼陀罗人物卡 / 地点图鉴 / 任务与好感度 / 撤回 / 自动存档与快照 / 分支切换与 IF 线时间轴 / 回溯与消息编辑 / 物品与战斗行动 / 随机冒险 / 掷骰(d20) / 随机事件 / 主题管理 / Pixiv 搜图看图器 / AI 成图保存 / 一键生成小说 / 离线小说引擎(火柴人)。
- 数据：知识库 50 本设定书 + 39 张角色卡；存档 IndexedDB；Obsidian 素材库（人读层）。

**Denova**（Go 单体 + React Web，Apache-2.0 开源）：
- Go 后端 **30 个 internal 模块**；前端 web/src 20+ 功能面。
- 功能面（实地）：书籍工程管理（BookSwitcher/BookForm/封面）、小说导入（NovelImportDialog）、酒馆角色卡导入（CharacterCardImportDialog）、写作编辑器（MarkdownRichEditor + 搜索替换 + 选区工具栏 + 文档审阅标注 + 冲突恢复）、Agent 对话面板（SubAgent/轨迹/上下文分析/token 用量）、版本面板（VersionPanel/ChangesList/AutoSummary）、变更审阅（diff-stats/change-review）、自动化（AutomationsView/定时触发/任务目录）、Skills 管理（SkillEditor/InstallPanel）、设置（模型/图像预设/远程访问）、互动叙事（interactive 模块：导演、回合、状态机、开局初始化、事件系统、检定规则绑定、历史检索）、消息中心、导航/快捷键/中英双语。
- 数据：本地工程目录 .denova/projects（现有 10 个工程，含「老板」101 条 lore）；资料库 items.json（resident/auto/manual）；版本账本 changes/ledger.jsonl + blobs；story-director-modules 18 个预设文件（actor-states 5 + event-packages 7 + rule-systems 6）；18 个 Skills。

### 1.2 整合动机

- 两平台功能互补但数据割裂：冒险对话的剧情无法进入 Denova 写作管线；Denova 的规划/版本能力无法反向驱动平台冒险。
- 用户需在两套工具间手动搬运（现状已做单向导出，但深度协同未通）。
- 重叠域（角色设定管理、剧情推进、版本、图像、上下文）存在重复建设与口径不一致。

### 1.3 预期收益

1. 单一数据源 + 各端视图：知识库权威，Denova/平台/Obsidian 各取所需。
2. 双引擎闭环：对话冒险 → 章节/设定 → 大纲/审稿 → 新冒险/IF 分支。
3. 版本可回溯：任何端改动进入统一账本，Diff/回滚跨端可用。
4. 一套交互语言：导航、弹窗、进度反馈、模式切换统一。

### 1.4 重叠域比较与优化空间（实地）

| 重叠域 | 平台（实地） | Denova（实地） | 优化空间 |
| --- | --- | --- | --- |
| 角色/设定管理 | 知识库 50+39、PNG 卡解析、chub 导入、NSFW/讲述者分类 | 资料库 items.json、CharacterCardImportDialog（酒馆卡原生导入）、lore 工具链 | 平台为权威源；Denova 原生导入通道保留；导出桥做设定书→lore（已实现） |
| 剧情推进 | 对话协议、IF 线时间轴、掷骰(d20)、随机事件、战斗行动 | director 导演台、story_turn_narrative、event_system_presets、rule_state、tellers | 平台已有掷骰/随机事件 UI——导演台移植应**对接现有掷骰体系**而非另起炉灶 |
| 写作生产 | 一键生成小说（10 回合一章、保留文风） | 写作编辑器、大纲/细纲/审稿（novel-lite/standard/heavy）、Change Review | 平台生成管线升级为大纲→细纲→章节，审稿按需引入 |
| 版本恢复 | IndexedDB 快照、IF 线存档点 | VersionPanel、ledger.jsonl + blobs、AutoSummary | 账本格式对齐（已规划 Step3），前端版本面板可借鉴 ChangesList |
| 上下文管理 | 压缩摘要、World Info 命中 | context-compaction、ContextAnalysis、token 用量 | 平台保持轻量；Denova 深度管理；不互相复制 |
| 图像 | AI 场景图、Pixiv 看图器(P1-P3)、成图保存 | chapter-illustration、interactive-image、封面、图像预设 | Pixiv 素材可进 Denova 工程；图像预设映射 |

## 2. 用户偏好与定位（实地核验）

- **文字冒险平台**：305 个函数中绝大多数服务于"对话即冒险"——流式对话、协议解析、即时渲染、IF 线、场景图。用户偏好是**即时、沉浸、剧情内容优先**。
- **Denova**：interactive 模块（100+ Go 文件）与写作/版本/Agent 前端证明其定位是**长线创作工程化**：导演规划、回合状态机、审稿、版本、自动化。
- 整合定位：**轻量对话驱动剧情，深度工作台承接创作**。平台主流程（打开即玩）不变；导演台/写作台/版本按需展开（渐进披露）。

## 3. 平台架构规划

### 3.1 总体架构

前端应用层（平台 SPA 为统一宿主 + Denova 工作台）+ 本地服务层（8099/8098/8097/8080 四服务 + 生成脚本）+ 共享数据层（知识库 / IndexedDB / Denova 工程 / Obsidian 素材库）。

### 3.2 模块划分（与实地功能对应）

| 模块 | 职责 | 实地承载 |
| --- | --- | --- |
| 文字对话模块 | 对话冒险主流程 | 平台 app.js（305 函数主体） |
| 写作模块 | 大纲/细纲/章节/审稿 | 平台 buildNovel*（升级）+ Denova 写作编辑器/审稿 |
| 游戏模式模块 | 导演台/状态/事件卡/检定 | 平台 掷骰/随机事件（对接）+ Denova interactive（移植裁剪） |
| 素材管理模块 | 设定/角色治理与互通 | 平台知识库 + denova_lore_sync + Denova 资料库/卡导入 |
| 版本管理模块 | 快照/账本/Diff | 平台快照（升级）+ Denova ledger/blobs 对齐 |
| 图像模块 | 场景图/Pixiv/插画/封面 | 平台 Pixiv 桥 + Denova 图像 |
| 设置模块 | API/NSFW/代理/主题 | 平台设置页 + Denova 设置（独立保持） |

### 3.3 共享用户系统

本地单用户：统一设置页（API 多模型、NSFW、代理、Pixiv token、导出目标）；偏好随导出携带。

### 3.4 共享数据层（单一可信源）

- 知识库 = 设定/角色权威源；平台 IndexedDB = 冒险存档；Denova 工程 = 写作/互动产物。
- 同步链路：①设定书→lore（已实现）②冒险→工程（已实现：设定/角色/摘要/章节/全文/设定文档/进度条）③lore→设定书（已实现）④写作产物→冒险素材（规划）。

### 3.5 导航结构

- 平台顶栏保留现有 11 个一级入口；规划新增「导演台」「写作台」「版本」三入口（渐进披露，默认折叠）。
- 模式切换（对话/写作/游戏）显式触发，上下文保留。

## 4. 功能整合方案

### 4.1 去重逻辑（实地）

| 功能 | 处理 |
| --- | --- |
| 角色卡管理 | 平台保留；Denova 用原生 CharacterCardImportDialog；不双写 |
| 设定书管理 | 知识库权威 → lore 单向同步（已实现）；反向导入仅做迁移用 |
| 掷骰/检定 | **平台已有 parseDiceNotation/rollDiceNotation/dice 菜单**；Denova rule_system 提供难度/风格模板（6 种 DM）——融合为"平台 UI + Denova 规则模板" |
| 版本 | 平台快照与 Denova ledger 语义统一，存储分端 |
| 图像 | 平台 Pixiv/场景图 ↔ Denova 章节插画/封面，导出映射 |

### 4.2 互通与协同（双引擎闭环）

1. 灵感 → 设定（知识库/素材库）
2. 设定 → 对话冒险（平台挂载）
3. 冒险 → 章节/摘要（一键生成 + 导出，已实现）
4. 章节 → 大纲/细纲/审稿（Denova 写作管线，已具备通道）
5. 大纲/设定 → 新冒险/IF 分支（规划：写作产物反向挂载）
6. 导演状态 ↔ 对话协议（规划：[EVENTS]/[CHECK] 区块对接现有掷骰体系）

### 4.3 平台现有可复用资产（实地发现，避免重复建设）

- 掷骰体系（d20 + 属性检定 + 随机事件）
- 命令面板 Ctrl+K、右栏 Tab、抽屉布局
- 进度条/阶段反馈（denovaExportModal，可推广）
- World Info 注入（与 Denova lore auto 语义对应）
- PNG 角色卡解析（extractCharaFromPNG）
