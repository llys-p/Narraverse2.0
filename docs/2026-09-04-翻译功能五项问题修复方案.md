## 1. 问题 1「模型未产生可用中文译文」+ 问题 2「中英文混杂」

### 1.1 根因（已核实）

`tools/denova_full_export.py` 的 `LocalTranslator.translate()`（387-471 行）：

- **单块译文从不校验是否含中文**。HY-MT-1.8B 对某个 chunk 回显英文原文时，只要其他 chunk 正常，最终拼接结果 ≠ 原文，`denova_full_export.py:983` 的全局检查（`translation == source_text`）无法拦截 → 混杂输出被缓存并当成功保存（问题 2）。
- 若模型对全部 chunk 回显，全局检查发现译文 == 原文，抛「模型未产生可用中文译文」（问题 1）。**翻译层没有任何重试**，第一次回显即整条失败。
- 现有坏缓存（混杂/回显结果）已按 `cache_key` 落盘，改 prompt 不改缓存键版本号的话会继续命中坏缓存。

### 1.2 修改内容

**文件：`tools/denova_full_export.py`**

(1) 第 31-32 行，作废坏缓存：

```python
TRANSLATION_PROMPT_VERSION = 7        # 6 → 7
TRANSLATION_VALIDATOR_VERSION = 7     # 6 → 7
```

（`TRANSLATION_CACHE_VERSION` 保持 10 不动。）

(2) `LocalTranslator` 新增字数统计工具方法（放在 `needs_translation` 之后）：

```python
@staticmethod
def _latin_cjk(text: str) -> tuple[int, int]:
    return (
        len(re.findall(r"[A-Za-z]", text or "")),
        len(re.findall(r"[\u3400-\u9fff]", text or "")),
    )
```

(3) 第 447 行 faithful_zh prompt 加强（显式禁止复述原文/解释）：

```python
prompt = (
    "把下面的文本翻译成简体中文。要求：只输出译文；不要复述原文；不要解释或添加注释；"
    "不要添加引号；保留 __NV_*__ 占位符原样不变。%s\n\n%s"
) % (terminology, model_chunk)
```

(4) 抽出单次模型调用 + 新增重试包装（核心修复）。把 448-458 行的 ollama 调用抽成 `_call_model(prompt)`，然后在 `translate()` 的 chunk 循环里改为：

```python
output = self._translate_chunk(prompt, model_chunk, terminology, mode)

def _translate_chunk(self, prompt: str, model_chunk: str, terminology: str, mode: str) -> str:
    output = self._call_model(prompt)
    probe = re.sub(r"__NV_(?:PROTECTED|EXISTING_ZH)_\d{4}__", "", model_chunk)
    latin_src, _ = self._latin_cjk(probe)
    latin_out, cjk_out = self._latin_cjk(output)
    need_retry = False
    if mode == "faithful_zh" and latin_src >= 8:
        # 整块回显英文（问题 1）或英多于中（问题 2）都重试一次
        need_retry = cjk_out == 0 or (latin_out > latin_src * 0.6 and latin_out > cjk_out)
    elif mode == "name_zh" and re.search(r"[A-Za-z]", output) and re.search(r"[A-Za-z]", probe):
        need_retry = True
    if not need_retry:
        return output
    retry_prompt = (
        "请把以下英文文本完整翻译成简体中文，只输出中文译文，"
        "不得出现英文句子，保留 __NV_*__ 占位符。%s\n\n%s"
    ) % (terminology, model_chunk)
    second = self._call_model(retry_prompt)
    latin2, cjk2 = self._latin_cjk(second)
    if cjk2 > cjk_out:
        output = second
    latin_best, cjk_best = self._latin_cjk(output)
    if mode == "faithful_zh" and latin_src >= 8 and cjk_best == 0:
        raise RuntimeError("模型未产生可用中文译文（模型回显原文，已重试一次）")
    return output
```

行为变化：回显原文 → 自动换强提示重试一次，仍失败才报错且错误信息更可诊断（新文案「回显原文，已重试一次」）；混杂输出取两次中中文更多的一次，不再轻易整体失败。

(5) 第 982-984 行队列 worker 的全局检查保留不动（兜底）。

### 1.3 影响与验证

## 2. 问题 3「应用翻译后条目不更新」——手动同步按钮（用户已拍板）

### 2.1 根因（已核实）

- `denova-src/internal/api/handlers/handler_library.go:191`：`HandleLibraryProposalApply`（精修/恢复 Proposal 应用）只写总库，**从不触发冒险投影**；批量应用（`batch-apply`，199 行）同样。
- `denova-src/internal/book/material_import.go:362`：即使 HY-MT 队列路径（`handler_material.go:72`）触发了 `FinalizeMasterImport`，**事务已是 `instantiated` 时直接 early-return**，不重投影。
- `denova-src/internal/book/master_library.go:586-589`：`PrepareAssetInstantiation` 对已加入冒险的资产永远返回旧 instance 的 importID，不会用新 `ActiveWorkingRevision` 生成新实例。
- 结论：条目一旦进入冒险，之后任何总库翻译更新都到不了冒险副本，且目前无任何同步入口。

### 2.2 修改内容（手动同步，不破坏「不静默覆盖」原则）

**(1) Go 后端：重投影方法**

`denova-src/internal/book/material_import.go`，在 `FinalizeMasterImport`（356 行）后新增：

```go
// ReprojectMasterImport 把总库当前 active 工作版重新投影到已实例化冒险的目标
// 资料条目（就地更新）。由用户显式触发，不静默执行。
func (s *Service) ReprojectMasterImport(importID string) (MaterialImportResult, error) {
    master := NewMasterLibraryStore(s.workspace)
    transaction, err := master.LoadImport(strings.TrimSpace(importID))
    if err != nil { return MaterialImportResult{}, err }
    if !master.TransactionTargetsAdventure(transaction) {
        return MaterialImportResult{}, errors.New("该导入事务不属于冒险投影")
    }
    if transaction.Status != "instantiated" {
        return MaterialImportResult{}, errors.New("素材尚未加入冒险，请先从总库加入")
    }
    source, revision, data, err := master.LoadSourceRevision(transaction.SourceID, transaction.SourceRevision)
    if err != nil { return MaterialImportResult{}, err }
    items := /* 按 transaction.ItemIDs 逐个 master.LoadItem */
    store := NewLoreStore(s.workspace)
    existing, err := store.ListAll()
    if err != nil { return MaterialImportResult{}, err }
    ops, _, itemTargets, nestedLoreIDs, err := buildMasterRuntimeOperations(source.Filename, data, items, transaction, existing)
    if err != nil { return MaterialImportResult{}, err }
    byID := map[string]LoreItem{}
    for _, item := range existing { byID[item.ID] = item }
    updateOps := make([]LoreOperation, 0, len(ops))
    for _, op := range ops {
        if _, found := byID[op.Item.ID]; !found { continue } // 不存在的不补建，保持语义
        target := op.Item
        // 名称唯一性冲突时保留旧名（lore.go update 分支会因重名报错）
        if loreItemNameIndex(existing, target.Name, target.ID) >= 0 { target.Name = "" }
        updateOps = append(updateOps, LoreOperation{Op: "update", ID: op.Item.ID, Item: target})
    }
    result := emptyMaterialImportResult()
    result.ManagementMode, result.Status, result.ImportID = MaterialModeManaged, "synced", transaction.ImportID
    result.MasterWorkspace, result.MasterSourceID = master.Workspace(), transaction.SourceID
    result.MasterItemIDs = append([]string{}, transaction.ItemIDs...)
    if len(updateOps) > 0 {
        applied, applyErr := store.ApplyOperations("从叙界总资料库同步「"+source.Filename+"」", updateOps)
        if applyErr != nil { return MaterialImportResult{}, applyErr }
        for _, item := range applied.Updated { result.ItemIDs = appendUnique(result.ItemIDs, item.ID) }
    }
    // 刷新 instance 的 LoadedRevision，避免无限提示「有新版」
    // 复用 MarkImportInstantiated 语义：LoadedRevision = item.ActiveWorkingRevision
    _ = itemTargets; _ = nestedLoreIDs // 复用 Finalize 的 instance 组装逻辑刷新 LoadedRevision
    return result, nil
}
```

(2) 重写 `polishField`（359-367 行）为「启动 + 轮询候选」：

```ts
const polishField = async (field: MasterTranslationFieldRuntime) => {
  if (polishingPaths.has(field.field_path)) return
  const started = Date.now()
  try {
    await startMasterAgent(masterItemID, field.field_path, 'polish')
  } catch {
    setActionMessage(t('library.agentUnavailable'))
    return
  }
  setPolishingPaths((prev) => new Set(prev).add(field.field_path))
  setActionMessage(t('library.agentProcessing'))
  const finish = (message: string) => {
    setPolishingPaths((prev) => { const next = new Set(prev); next.delete(field.field_path); return next })
    setActionMessage(message)
    setReloadToken((value) => value + 1)
  }
  const poll = async () => {
    try {
      const list = await fetchMasterAssetProposals(masterItemID)
      const ready = list.proposals.some((p) =>
        p.field_path === field.field_path &&
        (p.status === 'candidate_ready' || p.status === 'validated') &&
        Date.parse(p.updated_at || p.created_at || '') >= started - 1000)
      if (ready) { finish(t('library.polishCandidateReady')); return }
    } catch { /* 继续轮询 */ }
    if (Date.now() - started > 120000) { finish(t('library.polishTimeout')); return }
    window.setTimeout(() => void poll(), 3000)
  }
  window.setTimeout(() => void poll(), 3000)
}
```

## 7. 风险

- **坏缓存作废**：首次重译有额外耗时，属一次性。
- **重试延迟**：坏 chunk 最多 2 次调用，最坏单块延迟 ×2（180s 超时不变）。
- **同步按钮覆盖语义**：冒险副本的名称/简介/正文/关键词会被总库当前 active 文本覆盖（用户手动触发，已确认接受）；冒险本地的启用状态、图片、provenance 保留（lore.go update 分支 firstNonEmpty 语义）。
- **精修轮询**依赖 Proposal 落盘可见，不感知 Agent 进程级崩溃；120s 超时文案已提示人工查看。
