## P1：可独立规划的产品方向

### Knowledge Workspace（Phase 5 候选）

目标：对书籍、章节、资料和摘录做结构化整理，为 Master Library 与 World 提供可追溯参考。

前置：先确认输入来源、隐私范围、选择式读取规则与引用契约 `sourceKind/sourceId/sourceRevision/locator`。

不做：自动全量读取小说/Obsidian vault、直接把分析结果写入 World、把知识层当成 World 真源。

### Knowledge Graph（Phase 6 候选）

目标：可视化人物、地点、事件、组织、物品和来源关系。

前置：Knowledge Workspace 的稳定引用和用户可核查的关系来源。

不做：将图谱当作事实数据库，或让图谱编辑自动修改 World。

### Module4 V2（概念已保留，未开发）

目标：研究事件驱动的自由沙盒体验。原始玩法基线在 `future/module4/`。

前置：独立规格、性能/成本预算、运行态与 World 的单向边界，以及可验收的最小玩法闭环。

不做：借由“世界会变化”绕过 World 真源、让 Agent 自主改核心数据、直接重写现有 Module4。

### 三模式游玩体验（历史提案，待重新验证）

目标：降低游戏模式的信息密度、澄清叙界与规则层的体验职责。原提案在 `future/legacy-proposals/three-mode-play/`。

前置：重新对照当前 UI、ModeRouter 和 Phase 3.2 运行边界；旧方案不能直接照搬。
