第一部分：模式定位、核心数值与阶段系统1. 模式定位名称：Denova 养成攻略模式
类型：多女角色同时推进的数值养成 + 攻略系统
视角：男主视角为主
核心体验：角色设定整理与欣赏 + 通过行动提升数值、解锁阶段、观看面板成长
深度：中等偏上，适合较长时间养成
题材：不限，以系统为优先
多角色支持：可同时推进多名女角色，具备后宫经营感

2. 核心数值（固定6项）亲密度  
依赖  
顺从  
羞耻  
沦陷值  
性欲值

数值规则：每次有效互动后，清晰弹出多个具体数值变化（例如：亲密度 +2、沦陷值 +1、性欲值 +3）
不同数值的高低组合，从中期开始影响阶段称号与描述
最终形态由数值自由组合决定，可产生多种不同结局/身份
示例路线参考：亲密度高 + 其他数值正常 → 恋人路线
沦陷值高 + 性欲值高 → 荡妇 / 肉便器路线
其他组合可衍生更多最终状态

3. 阶段系统（每个角色固定4-5个大阶段）初识 / 普通阶段  
亲近 / 信任阶段（中期开始出现路线分化）  
深入 / 依赖阶段  
深度绑定阶段  
最终形态（数值自由组合，多种可能性）

阶段提升时的即时反馈（必须同时出现）：称号更新
简短状态描述变化
H面板新增可提升项目

第二部分：行动系统、界面与互动流程4. 行动系统行动方式：自由行动列表（无强制日程表）
主要行动类型：陪伴
送礼
特殊互动

行动之间无强制手感区分
每回合 / 每天建议有效互动次数：3-5次
支持同时对多名女角色进行行动

5. 界面结构总览面板
可切换查看所有已攻略/可攻略女角色的当前阶段、关键数值与简要状态
沉浸式单人详细面板（主要操作界面）
包含：当前称号 + 简短状态描述
6项核心数值进度条
H面板区域（可折叠）
行动按钮（陪伴 / 送礼 / 特殊互动）
已解锁设定与成就入口

6. 完整互动流程从总览面板选择目标角色，进入单人详细面板
选择行动（陪伴 / 送礼 / 特殊互动）
进行简短文字互动
清晰弹出多个具体数值变化
互动结束自动检查：是否触发成就（计入收集图鉴与成就列表）
是否满足阶段提升条件

若触发阶段提升：立即更新称号、状态描述，并在H面板新增可提升项目

7. 成就系统定位：收集要素
形式：图鉴 + 成就列表
用途：记录重要节点、路线达成、阶段突破等，提供长期收集目标

第三部分：H面板框架、扩展规则与长期目标8. H面板框架与扩展规则基础框架（所有角色初始可见）：性经验等级（从 Lv.0 起）
基础敏感度
性欲积累（与核心性欲值同步）
已解锁行为列表
当前状态简报（一句话非细节描述）

扩展规则：每提升一个大阶段，H面板新增可提升项目
新增项目与当前路线（数值倾向）相关
部分深层项目需额外满足数值阈值才可出现

阶段对应扩展节奏：第1阶段：仅基础框架
第2阶段：新增敏感带提示（笼统分类）、初步行为熟练度
第3阶段：新增专项敏感度分类、额外行为解锁槽、简单承受/恢复相关数值
第4阶段：新增路线专属项目、进阶熟练度或特殊状态槽
第5阶段：新增最终形态专属项目、可长期培养的深层成长项、完成度指示

联动规则：性欲值、沦陷值、羞耻直接影响H面板项目的解锁速度与上限
亲密度、依赖、顺从主要影响阶段称号与最终路线，从而决定H面板的扩展分支

显示原则：默认折叠，需手动展开
只显示进度、等级、解锁状态与简短标签
不包含任何具体生理细节描写

9. 长期目标与节奏通过反复行动与数值组合，追求多种不同的最终状态
支持横向对比不同女角色的成长路径
成就收集提供额外长期目标
整体节奏兼顾日常缓慢积累与关键节点的明显跃升
