## 本工作树完成的内容

### 1. 完整归档

新增本目录下的三份原对话阶段归档之后的补充材料，并保留原有三份文档不改写。归档目标是让后续 AI 同时获得：

- Module4 P0 的历史背景与架构合同；
- 当前真实 Git/远端/发布状态；
- 本工作树后来发生的改动与决策；
- 下一步收束 PR 的边界。

### 2. Module4 行动可观察性

当前补丁在统一 Action Executor 完成主要行动后记录 `world.actionLogs`，最多保留最近 100 条，包含行动类型、来源、文字、结果描述，以及行动前后的 Day、时段、地点和精力。

查看状态、查看世界、查看日志等免费查看类操作不会写入行动日志。旧世界没有 `actionLogs` 时迁移为空数组；未知旧字段不会因本次扩展而被静默删除。

### 3. Preview 可玩性与完整性

Preview 校验现在要求每个 NPC 的 morning / afternoon / evening 时段都有可展示的行动内容；有地点的世界还会校验地点引用。模型结果不完整时，已有 fallback 会生成确定性的三段短日程骨架，不放宽已有解析入口去接受错误结构。

`Preview.isCurrentDayValid()` 与 UI 使用同一套当前日和完整性判断，避免页面显示“已生成”但下方日程为空或不可用。

### 4. PlayView 表达与检查入口

PlayView 会把地点 id 显示为地点名，将缺失安排明确显示为“安排缺失”，并在不干扰正常游玩的折叠区域提供“试玩检查”：

- 当前 Preview 状态；
- 当前 Day、时段、地点和精力；
- NPC 三段日程；
- 最近玩家行动结果。

这是一层可观察性补丁，不是 P1 玩法，也没有新增 AI 互动、地点移动规则、Judgment 档位或 Facts 体系。
