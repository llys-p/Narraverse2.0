## 一、这个 Demo 是什么

一句话定位（与 V2 的根本区别）：

> **世界工作区 = 世界的舞台、资料上下文与长期记忆；现有 Denova 侧栏 = 创作和运行的操作系统。**

V3 不重做 Narraverse，也不新建一套平行的 Agent / 预设 / Skill / 写作 / 游戏系统。它展示的是：现有平台控制平面（版本管理、书籍管理、总资料库、方案预设、Skills、Agents、自动化、设置）如何作为"操作系统"存在，而世界工作区如何作为这些既有能力**所使用的世界上下文、资料入口与事实记忆层**接入其中。

```
现有方案预设 / Skills / Agents / 自动化
                ↓
          平台控制平面（操作系统）
                ↓
  世界工作区：世界资料、角色实例、时间线、事实、任务
                ↓
     写作模式｜结构化游戏｜叙界｜开放沙盒
                ↓
     事实提案 → 用户确认 → 世界历史
```

---

## 二、三层信息架构

界面明确分为三层，用户不会混淆"书籍 / 世界 / 冒险实例 / 角色原件"：

| 层 | 内容 | 界面位置 |
|---|---|---|
| 平台控制平面 | 版本管理 · 书籍管理 · 总资料库 · 方案预设 · Skills · Agents · 自动化 · 设置 | 左侧固定 rail（8 项），点击打开抽屉展示"现有模块 + 与世界工作区的关系" |
| 当前世界工作区 | 概览 · 资料绑定 · 角色 · 时间线 · 世界事实 · 任务与健康 | 左侧工作区导航（6 页） |
| 四个运行模式 | 写作模式 · 结构化游戏 · 叙界 Narraverse · 开放沙盒 | 顶部模式三 seg + 各模式内部上下文条 |

顶栏三段恒常可见：`工作区《黑月挽歌》 / 世界 黑月大陆 / 模式 世界工作区`，另含"事实提案 N 待确认"徽章与"世界版本 r17"标签。

## 三、各页面说明

### 1. 世界工作区概览
首屏只回答四件事：**这个世界现在发生什么 / 它使用了哪些资料与角色 / 我从哪里进入体验 / 有什么需要处理**。包含当前世界时间、近期事件、三条世界指标、已绑定资料与角色摘要、四个模式入口卡、待处理任务与事实提案。地图/势力/装备/生物等全部降级到二级页（时间线页内的势力与地区简表），不在首页堆砌。

### 2. 资料绑定
展示 `总资料库原始资产 → 当前世界绑定 → 世界内角色/设定实例` 的关系。严格区分：原始角色卡、原始设定书、世界内实例、翻译/版本状态（已翻译 / 待翻译 EN-CN / 草稿）、绑定状态（已绑定 / 待处理 / 已归档）。模拟导入流程为：选择文件 → 解析与字段预览 → 缺失项/冲突/译文状态 → 用户确认绑定；"点击导入"不会假装已真实写入资料库。

### 3. 角色中心与角色档案
双层信息：**原始角色资料**（身份、种族、外貌、性格、背景、基础技能 —— 只读，来自总资料库）与**世界内角色状态**（所属势力、当前地点、近期动态、装备、成长路线、关系、角色已知信息 —— 属于世界实例，不回写原始角色卡）。有头像用头像，无头像用首字占位（本 Demo 全部为虚构角色，用首字色块）。

### 4. 四个模式入口
四张入口卡（非 V2 的三张），每张说明：是什么体验 / 读取哪些世界上下文 / 使用哪些既有能力 / 返回世界后可能产生什么事实提案。

| 模式 | 既有能力映射（界面文案使用） |
|---|---|
| 写作模式 | 写作 Agent、叙事风格、章节与版本、/outline /continue /rewrite、小说流程 Skills |
| 结构化游戏 | 游戏叙事 Agent、后台导演 Agent、Story Director、Actor State、事件包、检定系统 |
| 叙界 Narraverse | 现有叙界冒险、角色卡与世界书、对话式体验 |
| 开放沙盒 | Module4 世界时钟、日程、行动、Facts、日结与世界变化、自动化 |

### 5. 模式内"世界上下文条"
写作 / 游戏 / 叙界 / 沙盒四个页面顶部一致的低干扰上下文条：`当前世界：黑月大陆 · 已加载：4 条规则 · 3 名角色 · 12 条已确认事实 · 世界版本 r17 [查看世界上下文] [返回世界工作区]`。它不是设置页——模式内**不允许**修改模型、预设、Skills 或 Agent 权限。

### 6. 任务与健康中心
取代 V2 的"四个 Agent 永远运行中"。七种状态：待命 / 排队中 / 运行中 / 等待确认 / 已完成 / 失败 / 已停止。六条任务示例：解析角色卡（总资料库 + 配置管理 Agent）、检查设定冲突（/master-library）、写作 Agent 生成章节草稿（写作 Agent + /continue）、后台导演完成回合分析（后台导演 Agent + Story Director）、沙盒推进 7 天（Module4 运行时 + 自动化）、定时世界快照（自动化 · 定时任务）。每条任务显示来源模块、处理内容、影响哪些世界资料、结果、停止/重试/确认操作。不展示 API Key、完整提示词、完整存档或敏感日志。

### 7. 世界事实与提案机制（V3 核心）
原则：**模型建议不会自动写死世界**。

```
草稿 / 模型建议 → 事实提案 → 用户确认 → 已确认世界事实 → 时间线 / 角色 / 势力更新
```

事实至少区分六类：已发生事实、角色已知信息、玩家已知信息、未来计划、模型或 Agent 提案、被拒绝的提案。示例（内置两条待确认提案，完全按任务书口径）：
- **"林夜加入影裔教团"** → 不直接写入世界历史，显示为「剧情 Agent 提案」，影响：林夜关系 / 影裔教团势力 +3 / 第三纪元时间线；操作：查看依据 | 采纳 | 拒绝。采纳后真实改写林夜所属势力为"影裔教团（卧底）"、影裔教团影响力 +3、时间线追加"卧底线"。
- **"黑森林出现远古遗迹"**（沙盒推演提案）→ 影响：黑森林稳定 -8 / 冒险者公会 +4，采纳后真实更新地区与势力状态。

### 8. 开放沙盒（重点改进）
完整推进链路：`推进 1 天 / 7 天 / 1 季 → 生成事件候选 → 展示影响预测（谁响应 / 哪些势力变化 / 哪些地区受影响）→ 用户确认应用 → 更新世界状态 → 形成事实或提案`。

- 补齐**暂停 / 停止 / 重试（重新生成候选）**；
- 规则四滑杆带**含义说明、恢复默认、修改历史**（记入 ruleHist）；
- 三种身份**真正改变权限与可见信息**：
  - 观察者：可推进时间、查看候选与影响预测；事件 / 规则 / 角色介入卡片锁定；
  - 世界导演：可注入事件、调整规则、创建角色，看到完整影响预测；
  - 新角色：可创建角色进入世界并推进时间；注入事件与调规则需切回导演。
- 注入事件先成为提案（显示"谁响应、哪些势力变化、哪些地区受影响"），不直接写死；
- 用户创建的角色成为**世界实例**，不改写原始角色卡（界面文案明确标注）。

### 9. 平台控制平面抽屉
8 个入口（版本管理 / 书籍管理 / 总资料库 / 方案预设 / Skills / Agents / 自动化 / 设置）全部保持为"现有平台模块"，抽屉文案为"现有模块 + 与世界工作区的关系"，明确"Demo 仅展示入口与映射，不重建这些系统"。方案预设抽屉展示其真实管理内容（叙事风格、故事导演、Actor State、图像方案、互动开场），Skills 抽屉列出 /continue /outline /rewrite /novel-lite /novel-standard /novel-heavy /lore /lore-init /master-library。

## 四、真实平台映射 vs Demo 模拟

| 项 | 真实平台（正式架构） | 本 Demo 中的呈现 | 类型 |
|---|---|---|---|
| 平台控制平面 8 项 | Denova 侧栏真实模块 | 左侧 rail + 抽屉，仅展示入口与映射 | 真实映射 |
| 方案预设 | 管理叙事风格 / Story Director / Actor State / 图像方案 / 互动开场 | 抽屉只读展示内容清单 | 真实映射 |
| Skills | /continue /outline /rewrite /novel-lite… /master-library | 抽屉展示清单，写作页按钮文案引用 | 真实映射 |
| Agents | 写作 / 配置管理 / 游戏叙事 / 后台导演 / 图像 / 自动化 / 上下文压缩 | 任务页来源模块、模式页"使用"文案 | 真实映射 |
| 世界事实机制 | 未来产品形态（本 Demo 提出的产品概念） | 六类事实 + 提案确认流（可交互） | 产品概念演示 |
| 世界工作区 | 未来产品形态 | 概览 / 绑定 / 角色 / 时间线 / 事实 / 任务 | 产品概念演示 |
| 资料绑定流程 | 未来流程（总资料库 API 未开放写） | 模拟导入：选择 → 解析 → 冲突 → 确认 | Demo 模拟 |
| 写作 / 对白生成 | 写作 Agent 真实调用 | 固定草稿 + 模拟流式输出 | Demo 模拟 |
| 游戏回合裁定 | 游戏叙事 + 后台导演 Agent | 固定分支 + 模拟裁定日志 | Demo 模拟 |
| 沙盒推演 | Module4 运行时（真实时钟/日程/Facts） | 本地假数据推演 + 确认应用 | Demo 模拟 |
| 任务执行 | 真实任务系统 | 定时器驱动状态流转（排队→运行→确认/失败/停止） | Demo 模拟 |
| 世界版本 r17 | 真实世界/文档版本号 | 静态标签，任务确认后可手动推进（快照任务为 r17→r18） | Demo 模拟 |
| API Key / 敏感日志 | — | 一律不读取、不输出、不模拟 | 约束遵守 |

**不越界清单**：不修改 `app/`、`denova-src/`、`knowledge-base/`；不新建平行 Agent / Skill / 预设；不把模拟状态伪装成真实后台执行（所有模拟处均标注"Demo 模拟"）；不使用真实 API Key；V2 目录原样保留。

## 五、设计说明

- 延续 V2 设计系统：暖黑纸面 `#171614`、铜色 `#c99b58` 主强调、苔绿 `#8fae8d` 成功态、红色仅表风险/失败、细线分区、低玻璃感、无霓虹光晕、无紫蓝渐变。
- 中文正文 ≥14px；不使用斜体；选中态用整块底色/边框/字重（不用卡片左侧彩竖线）。
- 动效仅用于世界创建、任务进度、抽屉开合、状态反馈；全部 ≤300ms，并支持 `prefers-reduced-motion`。
- 宽屏三栏中高密度，窄屏收为单列。
- 无常驻"已载入 / 运行正常"式系统文案；加载、失败、空状态都给出下一步动作。

## 六、验证结果

- **语法**：从 index.html 提取 `<script>` 后 `node --check` 通过（修复过程记录：叙界对话数据内嵌引号转义、沙盒规则滑杆拼接误用逗号运算符、角色字段名 `n`/`name` 不一致，均已修复并复验）。
- **冒烟自测**：`index.html?smoke=1` 内置 17 项自测全部 OK：概览渲染 / 控制平面抽屉 / 资料解析 / 角色双层 / 提案采纳 / 提案拒绝 / 写作提案 / 游戏分支 / 叙界对话 / 沙盒推进到候选评审 / 沙盒应用候选 / 观察者权限拦截 / 角色介入 / 规则调整 / 任务运行至完成 / 任务等待确认 / 任务确认写入。
- **逐页截图**：`_shots/v1-v11.png`（1440×900，Edge 无头，独立 profile）覆盖 概览 / 资料绑定 / 角色中心 / 角色档案 / 时间线 / 世界事实 / 任务与健康 / 写作 / 游戏 / 叙界 / 沙盒，关键页已人工核对。

**仍存在的缺口**：全部数据为本地模拟（Mock），不接真实后端；沙盒推演与 AI 生成为预置数据 + 本地随机；世界版本推进为演示逻辑而非真实版本控制。
