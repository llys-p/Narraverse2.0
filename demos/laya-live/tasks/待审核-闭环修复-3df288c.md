## 背景：要守住的核心不变量

这是状态协议层，两条写入路径必须行为一致（旧路由 `/decide /turn /commit /reset` 与
新协议 `/analyze /commit_state /reject_analysis`）：

1. **版本原子性**：一次分析所用的「状态快照」与「基准版本」必须是同一时刻、同一把锁内捕获的；
   推理窗口内任何 Reset/Commit 都必须让该次分析作废（stale → 拒绝提交/登记），不允许旧计算冒用新版本提交。
2. **引擎身份**：fallback 启发式结果（真实引擎未就绪 / predict 抛异常后降级）**任何情况下不得**按"真实模型判断"
   语义写入状态或历史；新协议已有 503 门禁，本次补的是旧路由的对应门禁。
3. **Reset 换代全覆盖**：`/reset` 无论「全部」「按 session」还是「按 (session, actor)」形式，都必须对
   **每个受影响作用域**换 protocol generation，使该作用域的所有旧候选/旧 Pending/旧版本失效。
4. **TTL 终态化**：ready/reference_only 候选超过 READY_TTL 后，即使从未被查询也必须转为终态（可回收），
   不能让长期运行的进程因"永远未转终态的过期候选"堆积而频繁触发 429。
